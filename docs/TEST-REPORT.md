# Протокол проверки WiFiGuard

Дата последней проверки: **23 ноября 2026 года**, КТ4. Проверки выполнены агентом в текущей среде; отдельное пользовательское тестирование команды не заявляется.

## Среда и команды

Windows, Node.js 24.15.0. Автоматические тесты запускаются через `node --test`, без сторонних зависимостей. Интерфейс проверен Playwright в отдельном headless-профиле установленного Google Chrome; встроенный браузер и Windows Computer Use в этой сессии недоступны.

Основной браузерный сценарий: `node scripts/browser-check.mjs` при доступных Playwright и Chrome. Размеры основного прогона — 1366×940 и 375×812. Выбор четырёх устройств дополнительно проверен на ширинах 320, 375, 768 и 1024 px.

## Браузерный сценарий — пройден

- Полный опрос через элементы интерфейса, блокировка перехода без выбора ответа, результат 50.
- Возврат, редактирование и обновление страницы сохраняют ответы и текущий вопрос.
- Пример кафе: пропуск шифрования сохраняет 43; подтверждение подлинности, обновлений, автоподключения и VPN даёт 10. Сравнение показывает 43 → 10.
- Пример аэропорта: 75 и критическое предупреждение; первым открывается действие по порталу.
- Подтверждение отключения завершает оценку, сохраняет последний индекс 75 и восстанавливается после обновления.
- Пример с 0 баллов показывает ограничения и пустой список необходимых изменений.
- Полный сброс, клавиатурный фокус, открытие методики и закрытие Escape работают.
- Повреждённая запись сбрасывается; при заблокированном sessionStorage можно начать и проходить опрос.
- JavaScript-ошибок в основном сценарии не обнаружено. Запросов к сторонним адресам при прохождении сценария нет.
- Главная, опрос, результат и помощник не расширяют страницу за пределы проверенных размеров экрана.
- Для macOS проверены выбор устройства, полный опрос, отдельные инструкции Wi-Fi, обновлений и автоподключения, совет по общему доступу к файлам и восстановление выбранной ОС после обновления страницы. Сохранённые состояния остальных устройств продолжают проходить проверку.

## Исправления по результатам QA

В первой версии grid на главной расширял страницу до 416 px при ширине 375 px. Исправлены минимальные размеры элементов и геометрия иллюстрации. Убраны наложения плавающих карточек на заголовок примера; числовые вклады факторов больше не переносятся внутри дроби. Уточнён перевод фокуса после смены экрана. Тестовые селекторы изменены для скрытой на телефоне навигации; сам сценарий проходит через видимые элементы.

## Измеримые результаты и ограничения

### Проверки изменений 23 ноября 2026 года

Добавлены тесты анализа URL и истории в `test/portal-history.test.mjs`: HTTP/HTTPS, некорректный URL, `@`, IP, нестандартный порт, IDN/Punycode, точное совпадение домена и корректные поддомены, лимит и удаление записей истории. После добавления проверки подключения команда `npm test` выполнена успешно: 19 из 19 тестов прошли.

Для режима «Проверка текущего подключения» добавлены проверки Network Information API с доступными и отсутствующими данными, успешного same-origin ответа `/health`, измерения задержки и ошибки недоступного сервера. Обновлён серверный тест служебного endpoint и CSP `connect-src 'self'`. Локальный экран вручную проверен: сервер ответил, задержка отобразилась, недоступные характеристики получили нейтральное сообщение, пользовательские вопросы отображаются.

В первоначальном окружении автора новых функций полный скрипт `scripts/browser-check.mjs` не запускался из-за отсутствия пакета `playwright`. При подготовке публикации 23 ноября скрипт успешно выполнен в установленном Chrome с доступным Playwright.

Дополнительно проверены анализ URL, сохранение и удаление истории, восстановление истории после обновления, проверка доступности и печатная версия отчёта на ширинах 320, 375, 768 и 1366 px. Исправлен перенос кнопок главного экрана. Для статического хостинга добавлен ресурс `dist/health`, соответствующий локальному endpoint `/health`; это соответствие проверяется серверным тестом.

Критерий готовности КТ4: воспроизводимый полный сценарий на синтетических данных, объяснимый расчёт, работающий пересчёт, четыре ОС, локальный запуск и веб-ссылка. Измеренная программная корректность: 19/19 автоматических проверок и полный браузерный сценарий без ошибок после исправлений. Проверена монотонность на всех комбинациях ответов.

Изменение 43 → 10 демонстрирует изменение учебного индекса, а не измеренное сокращение вероятности реального взлома. Скорость прохождения «около 3 минут» — ориентир интерфейса, не результат замера на группе пользователей. Реальные сети не сканировались. Настройки Android/iOS/Windows/macOS не менялись автоматически. Safari, Firefox, физические смартфоны и компьютеры Mac отдельно не тестировались. Текст инструкций опирается на официальные справки, но пути зависят от версии ОС и производителя. Защита аккаунта и инфраструктуры хостинга не входила в тестирование.
