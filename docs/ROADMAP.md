# Идеи развития WiFiGuard

Идеи обсуждены 22 ноября 2026 года и сохранены для дальнейшего выбора. Они не входят в текущую реализацию и пока не утверждены к разработке. Поддержка macOS реализована отдельно от этих расширений.

| Идея | Возможности | Условия реализации |
|---|---|---|
| Анализ реального подключения | Название сети, тип аутентификации и шифрования, сигнал; автоматическое заполнение доступных параметров с указанием источника данных | Локальный модуль для Windows или нативное приложение. Обычный сайт не получает список окружающих Wi-Fi. Доступ зависит от разрешений ОС |
| Карта мест с публичным Wi-Fi | Поиск кафе, библиотек и других мест; адрес, оператор, условия доступа и SSID, если известен | Данные OpenStreetMap; проверка покрытия и актуальности для выбранного города. Наличие места в каталоге не подтверждает безопасность сети |
| Проверка ссылки на портал | Разбор URL, домена, HTTP/HTTPS, признаков необычного написания; проверка по базе известных угроз | Возможная интеграция Google Safe Browsing через сервер с API-ключом. Отсутствие совпадения с базой не является гарантией безопасности |
| Сообщения и репутация точек | Отдельные сообщения о качестве связи и подозрительном поведении портала | База данных, даты сообщений и модерация. Пользовательский рейтинг не подменяет техническую оценку |
| Сравнение с сохранённой сетью | Сопоставление текущих и ранее сохранённых параметров; предупреждения об изменениях | Локальный модуль для получения параметров. Изменения могут быть легитимными и сами по себе не доказывают подмену |
| История и экспорт | Сохранение проверок с датой и источниками данных, сравнение подключений, краткий отчёт | Явные настройки хранения и удаления данных; экспорт без паролей и других секретов |

При обсуждении наиболее полезным сочетанием названы реальные параметры подключения и проверка портала. Для варианта, работающего только по веб-ссылке, рассмотрены проверка портала и карта мест с Wi-Fi. Окончательный состав следующего этапа ещё не выбран.

## Источники для дальнейшей проработки

- [Network Information API](https://developer.mozilla.org/en-US/docs/Web/API/Network_Information_API) — возможности браузера.
- [Windows: сведения о доступной сети](https://learn.microsoft.com/en-us/windows/win32/api/wlanapi/ns-wlanapi-wlan_available_network) и [ограничения доступа](https://learn.microsoft.com/en-us/windows/win32/nativewifi/wi-fi-access-location-changes).
- [OpenStreetMap: internet_access](https://wiki.openstreetmap.org/wiki/Key:internet_access).
- [Google Safe Browsing: проверка URL](https://developers.google.com/safe-browsing/reference/rest/v5/urls/search).
